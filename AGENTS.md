# Repository Guidelines

## Start Here: Repository Instructions

Before making changes, read the canonical project guidance:

```bash
cat ./CLAUDE.md
find . -name CLAUDE.md -print
```

The root `CLAUDE.md` applies repository-wide. Read a nested `CLAUDE.md` when working in its directory or below it; currently, scoped guidance exists under `packages/boomer/` and `modules/nixos/opt/desktop/xmonad/`. Follow the closest applicable file alongside the root rules. Also consult `MODULES.md` before adding or renaming modules.
